

# How do you use this repository? 

You document your project work in this repository. A folder structure is already predefined. Templates exist in the folder **process** for your documentation of user stories, models, kick-off, and sprints.  

Folder | to add | to complete 
------- |------- |--------------
process | - | kick-off and sprints documentations 
process\product-increments\models | modeling artifacts | - 
process\product-increments\tests | test suites | - 
product | project proposal (as pdf) | - 
product\models | final models | - 
product\tests | final test suites | - 
product\presentation | video, app, website | - 

# Helpful external tools for modeling and collaborative working

You can use tools of your choice to create (UML) diagrams. However, the tool [TAPAAL](https://www.tapaal.net/) is mandatory for modeling timed-arc Petri nets. 

**Modeling tools for OCL and timed-arc Petri Nets**
- For class diagrams and OCL, e.g.: [USE](https://www.db.informatik.uni-bremen.de/projects/USE-2.3.1/) or [Eclipse OCL](https://projects.eclipse.org/projects/modeling.mdt.ocl)
- For timed-arc Petri Nets: [TAPAAL](https://www.tapaal.net/) (mandatory)

A selection of **web applications** for modeling (UML) diagrams and collaborative working are: 
- For collaborative working on texts, e.g.: [Hedgedoc](https://www2.tuhh.de/zll/hedgedoc/) 
- For modeling UML diagrams, e.g.: [draw.io](https://app.diagrams.net/)
